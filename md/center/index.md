# センターの概要（歴史・構成）

## 目的
伝統みらいセンターは、九州の伝統産業の技術伝承のあり方および知恵を明らかにするとともに、その知見を地域の活性化のために活用することにより、 我が国における未来のものづくりに寄与することを目的としています。

## 構成
運営組織は九州の伝統工芸の支援を行う地域産業研究部門と柿右衛門研究の深化を行う柿右衛門研究部門の二つです。
